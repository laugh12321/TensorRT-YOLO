把社区版装上，跑通一次推理

下面按社区版来写：C++ 一个头文件 trtyolo.hpp，Python 一次 predict。专业版接口不同，见 专业版。

从转换开始

先把已导出的 ONNX 转成可推理结构，再按下面步骤编译推理库、构建 engine。

$ pip install trtyolo-export

1. 依赖

  • CUDA ≥ 11.0.1
  • TensorRT ≥ 8.6.1
  • 操作系统：推荐 Linux（x86_64 或 ARM），也支持 Windows

2. 编译安装

git clone https://github.com/laugh12321/TensorRT-YOLO
cd TensorRT-YOLO
pip install "pybind11[global]"
cmake -S . -B build -D TRT_PATH=/your/tensorrt/dir -D BUILD_PYTHON=ON -D CMAKE_INSTALL_PREFIX=/your/tensorrt-yolo/install/dir
cmake --build build -j$(nproc) --config Release --target install

安装目录里有头文件、trtyolo 和 custom_plugins。构建 OBB / Segment / Pose 的 engine 时需要 TensorRT Plugin。把安装前缀加入 PATH，find_package 才能找到配置文件：

export PATH=$PATH:/your/tensorrt-yolo/install/dir   # Linux
# PowerShell
$env:PATH = "$env:PATH;C:\your\tensorrt-yolo\install\dir;C:\your\tensorrt-yolo\install\dir\bin"

若编译时打开了 BUILD_PYTHON，再装 Python 包：

pip install --upgrade build
python -m build --wheel
pip install dist/trtyolo-*-py3-none-any.whl

3. 模型转换

先把权重导出为 ONNX，再用 trtyolo-export 转结构，最后用 trtexec 出 engine。各系列和任务能否转换，见 模型支持。Detect 示例：

yolo export model=models/yolo11n.pt format=onnx batch=1
trtyolo-export -i models/yolo11n.onnx -o models/yolo11n-trtyolo.onnx -s
trtexec --onnx=models/yolo11n-trtyolo.onnx --saveEngine=models/yolo11n.engine --fp16

Pose / Segment / OBB 构建 engine 时还要加上 --staticPlugins 和 --setPluginsToSerialize，指向安装目录里的 libcustom_plugins。各任务完整命令见仓库 examples。

4. Python 推理

task 必须和导出时的任务一致。

import cv2
import supervision as sv
from trtyolo import TRTYOLO

model = TRTYOLO("yolo11n-with-plugin.engine", task="detect", profile=True, swap_rb=True)
image = cv2.imread("test_image.jpg")
result = model.predict(image)

box_annotator = sv.BoxAnnotator()
annotated_frame = box_annotator.annotate(scene=image.copy(), detections=result)

throughput, cpu_latency, gpu_latency = model.profile()
cloned_model = model.clone()

5. C++ 推理

#include <memory>
#include <opencv2/opencv.hpp>
#include "trtyolo.hpp"

int main() {
    trtyolo::InferOption option;
    option.enableSwapRB();

    auto detector = std::make_unique<trtyolo::DetectModel>(
        "yolo11n-with-plugin.engine", option);

    cv::Mat cv_image = cv::imread("test_image.jpg");
    trtyolo::Image input_image(cv_image.data, cv_image.cols, cv_image.rows);
    trtyolo::DetectRes result = detector->predict(input_image);

    auto cloned_detector = detector->clone();
    return 0;
}

分类、分割、姿态、旋转框分别用 ClassifyModel、SegmentModel、PoseModel、OBBModel。更多示例见 仓库 README。
