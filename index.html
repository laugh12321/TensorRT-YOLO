专为 NVIDIABuilt for NVIDIA

为 NVIDIA 设备而生Designed for NVIDIA hardware

不是通用框架的适配层。运行时、插件与图捕获都按 NVIDIA GPU 来设计，在 Linux / Windows、x64 / ARM 上同一套接口。 Not a generic adapter. The runtime, plugins, and graph capture are built for NVIDIA GPUs — one API on Linux / Windows, x64 / ARM.

  • TensorRT ≥ 8.6.1

    社区版硬下限。专业版要求 TensorRT ≥ 10。Community floor. Pro requires TensorRT ≥ 10.

  • CUDA Graph

    把启动开销压下去，让 GPU 走稳态。Cuts launch overhead so the GPU stays in steady state.

  • 专为 NVIDIA 设备NVIDIA devices only

    TensorRT Plugin 做后处理，CUDA Kernel 做前处理。TensorRT plugins for post-process, CUDA kernels for pre-process.

灵活易用Easier

一个头文件，一次 predictOne header. One predict.

C++ 引入 trtyolo.hpp，Python 一次 predict。同一套接口覆盖检测、分割、分类、姿态和旋转框。 Include trtyolo.hpp in C++. Call predict once in Python. The same API covers detect, segment, classify, pose, and OBB.

C++
#include "trtyolo.hpp"
Python
result = model.predict(image)
