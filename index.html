专为 NVIDIA

易用灵活、极致高效的 YOLO 系列推理部署工具。TensorRT Plugin 做后处理，CUDA Kernel 与 CUDA Graph 压低推理耗时，开箱即用，覆盖 YOLO 系列与变体。

能力

一套工具，覆盖导出到推理

社区版现在就能把常用任务跑起来。需要更高吞吐时，再看专业版。

开箱即用

C++ 一个头文件，Python 一次 predict。社区版 GPL-3.0，TensorRT ≥ 8.6.1。

C++ 与 Python

同一套推理接口，覆盖 Linux / Windows、x64 / ARM。

多种任务

目标检测、实例分割、图像分类、姿态识别、旋转目标检测，以及视频分析。

三步出 engine

导出 ONNX，trtyolo-export 转结构，再用 trtexec 构建。

加速走 GPU

TensorRT Plugin 加速后处理，CUDA Kernel 加速前处理，CUDA Graph 压低整体耗时。
