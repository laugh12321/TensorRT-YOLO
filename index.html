YOLO 部署。
专为 NVIDIA。

易用灵活、极致高效的 YOLO 系列推理部署工具。TensorRT 插件做后处理，CUDA 核函数与 CUDA 图压低推理耗时，C++ / Python 开箱即用。

model = TRTYOLO("yolo11n.engine", task="detect")
result = model.predict(image)

社区版 · GPL-3.0

公开仓库默认分支。C++ 单头文件，Python 一次 predict。TensorRT ≥ 8.6.1。

C++ / Python

同一条推理路径。Linux、Windows，x64 与 ARM。接口按开箱即用来做。

六种任务

目标检测、实例分割、图像分类、姿态识别、旋转目标检测、视频分析。

导出到 engine

YOLO 出 ONNX，trtyolo-export 转结构，trtexec 出 engine。

热路径在 GPU

TensorRT 插件加强后处理，CUDA 核函数做前处理，CUDA 图回放推理。
