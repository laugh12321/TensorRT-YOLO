YOLO 部署
专为 NVIDIA YOLO inference
Built for NVIDIA

易用灵活、极致高效的 YOLO 系列推理部署工具。TensorRT Plugin 做后处理，CUDA Kernel 与 CUDA Graph 压低推理耗时，开箱即用，覆盖 YOLO 系列与变体。 An easy, flexible, and high-performance toolkit for deploying YOLO models. TensorRT plugins handle post-processing; CUDA kernels and CUDA Graphs cut latency. Ready to use across YOLO families and variants.

result = model.predict(image)
